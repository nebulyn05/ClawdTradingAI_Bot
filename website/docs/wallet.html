Wallet Setup

Your wallet, generated inside Telegram.

Clawd Agents is non-custodial. The bot generates and holds keys for you, but you can export the raw private key any time — it works in any wallet that speaks Solana base58 or EVM hex.

Generate a fresh wallet

On first /start, the bot offers two paths: Create Wallet or Import Wallet. Tap Create and a fresh keypair is generated client-side. Only the public address gets stored; the private key is encrypted and bound to your Telegram user id before it ever touches the database.

Or import an existing one

Tap Import Wallet, paste your private key (Solana base58 or EVM hex). The bot validates the format, derives the public addresses for all chains, and registers the wallet. The plaintext key is wiped from chat history immediately on receipt.

Export the raw key any time

Open /wallet → Export Private Key. The bot reveals the plaintext key in a self-destructing message that auto-clears after 60 seconds. Copy it once into your password manager — that key works in Phantom, MetaMask, Rabby, anywhere.

Rotate the wallet when you want

/wallet → Generate New Wallet replaces the active wallet with a fresh one. The previous wallet stays in your record (you can re-export its key) but no new funds route to it. Useful for compartmentalising trades or starting fresh.

Safety checks

  • 01Private keys are encrypted at rest with a Telegram-user-id-derived key — no plaintext in any database.
  • 02Decryption only happens on your /wallet → Export request, in-memory, and the response auto-deletes after 60s.
  • 03No browser extension, no separate app, no MetaMask popup — fewer surfaces, fewer attack vectors.
  • 04You can export and use the key in any wallet you want — the bot doesn't lock you in.
Important

Anyone with your private key has full control of your funds. Never paste it into a website, never share it in DM, never screenshot it. The 60-second auto-delete is a backstop, not a substitute for caution.
