Rug Protection

Memecoin trading is full of traps — fake teams, frozen tokens, instant rugs. Four built-in safety checks reject those before your money ever moves. You don't see the rejected trades; you only see the clean ones.

Important Disclaimer

No risk engine is infallible. While Clawd Agents dramatically reduces exposure to malicious tokens using advanced AI analysis, meme coin trading carries inherent risk. Only deploy capital you can afford to lose.

Protection Pipeline

When a new token is detected, all four layers run in parallel. If any single layer flags the token, the trade is blocked.

LAYER 01

Locked Liquidity Check

99.1%
Detection accuracy

We make sure the token's liquidity pool is locked before buying. If it isn't, the team behind the token can pull all the money out at any time — that's a classic rug pull.

How it works

  1. 1Confirms the pool is locked through a known locker (TeamFinance, Unicrypt, PinkSale, etc.)
  2. 2Requires at least 80% of liquidity locked for a minimum of 30 days
  3. 3Skips the trade entirely if liquidity is unlocked or partially locked
  4. 4Re-checks live before each entry — locks can expire
LAYER 02

Team Reputation Check

847K+
Wallets profiled

We look up the wallet that launched the token. If it has rugged before, or matches patterns we've seen on past scams, the trade is blocked before money moves.

How it works

  1. 1Cross-checks against a database of 847K+ wallets tied to past launches
  2. 2Flags wallets that have rugged previous projects, even with new addresses
  3. 3Considers wallet age, activity, and prior token launches
  4. 4Scores from 0 (clean) to 100 (confirmed scammer) — anything risky gets skipped
LAYER 03

Honeypot Test

0
Honeypots entered

Some memecoins let you buy but secretly block you from selling — those are honeypots. We dry-run a buy AND a sell offline before any real money moves, so you never get stuck holding.

How it works

  1. 1Runs a buy + sell simulation against the live pool — zero real funds risked
  2. 2Measures the actual sell tax — some tokens hide a 99% sell fee
  3. 3Detects sell-blocking logic that only triggers after the buy
  4. 4Skips the token if the simulated sell fails or the tax is unreasonable
LAYER 04

Contract Safety Scan

< 50ms
Scan time

Even if everything else looks fine, the token's code itself can hide traps — hidden minting, owner-only sells, blacklists. We read the contract for these red flags before trading.

How it works

  1. 1Scans the contract for known rug patterns
  2. 2Flags dangerous powers like unlimited mint, blacklist, pause, ownership transfer
  3. 3Confirms ownership is renounced or split — no single wallet can override the token
  4. 4Combines all checks into a single safety score; risky tokens never trade
