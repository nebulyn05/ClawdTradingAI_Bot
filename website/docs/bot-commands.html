In the chat

Menu Walkthroughs

Most navigation is tap-driven through inline keyboards — you don't need to remember commands. Here's what each main screen looks like in practice.

Wallet

Fund the bot once, see what you've got.
  1. 1Tap Wallet — see balance, USD value, and copyable address per chain.
  2. 2Generate a fresh wallet, or import one with a private key / seed phrase.
  3. 3Send native coin (SOL, ETH, BNB) to your address. Bot confirms in chat with USD value frozen at receipt.
  4. 4Live multi-chain — one entry, balances on Solana, Ethereum, BSC, Base, Monad, and Robinhood.

Portfolio

Watch the AI work without scrolling charts.
  1. 1Tap Portfolio — see total value across all chains.
  2. 2Per-asset breakdown shows what's held, average entry, current price, and PnL.
  3. 3Trade history below — every entry / exit logged with the chain and timing.
  4. 4Updates automatically — no refresh button needed.

Referral

Get paid when your invites trade.
  1. 1Tap Referral — your link, signups, and earnings.
  2. 2Pick a custom code (e.g. r_yourname) so the link reads naturally.
  3. 3Share the link anywhere — Twitter, Discord, group chats.
  4. 4Earnings stream into your wallet whenever an invitee trades through the bot.
