One-time setup:
npm install                    # installs all workspaces (including the new apps/website)
docker compose up -d           # local Postgres + Redis
npm run db:generate            # prisma generate
npm run db:migrate             # applies migrations
npm run build                  # tsc -b across packages/bot/worker, so apps/admin can resolve @clawd/* imports

Running the pieces (each is its own process — run in separate terminals, or backgrounded):
npm run dev:bot                # Telegram bot
npm run dev:worker             # trading pipeline (Guard/Router/etc.)
npm run dev:admin              # admin dashboard — http://localhost:3000 (Next.js default port)
npm run dev:website            # marketing site — http://localhost:8080

Notes:
dev:bot and dev:worker need your .env filled in (Telegram bot token, RPC URLs, MASTER_ENCRYPTION_KEY, DATABASE_URL, REDIS_URL at minimum — see .env.example).
dev:admin needs npm run build done first (it imports the compiled output of @clawd/core/@clawd/db/etc., not source).
dev:website has zero backend dependencies (no DB, no .env needed) — safe to run on its own anytime.
You don't need all four running to work on any one of them — dev:website in particular is fully independent.
npm run serve:website still exists if you ever want to compare against the old static snapshot, but that's reference-only now.
